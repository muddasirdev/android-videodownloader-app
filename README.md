# Android Video Downloader

A Java Android app project with screens for handling video and status media from supported social apps.

## Included

- Separate screens for Facebook, WhatsApp, YouTube, and ShareChat
- Video and image tabs with Android Views
- Download and media handling libraries
- Gradle wrapper for opening and building the project

## Run locally

1. Clone the repository and open it in Android Studio.
2. Sync Gradle and run the `app` configuration on a device or emulator (minimum SDK 21).

This is an older Android project that uses third-party extraction libraries. Verify that dependencies still resolve and review the terms and copyright rules of each source platform before distributing an app or downloaded media.
